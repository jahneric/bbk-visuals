# bbk visuals – echo

Live-Visuals für bbk-Abende: Eine Kamera filmt den DJ, die Silhouette läuft mit Echos,
Nebel und Logo-Laufband über den Beamer. Läuft komplett im Browser (am besten Chrome),
auf Windows und Mac.

## Direkt im Browser

**https://jahneric.github.io/bbk-visuals/** öffnen und Kamera erlauben. Fertig – nichts installieren.
(Braucht Internet beim Laden.)

## Offline (für den Abend)

1. Oben rechts **Code → Download ZIP**, entpacken.
2. Windows: `start.bat` doppelklicken. Mac: `start-mac.command` doppelklicken
   (beim ersten Mal: Rechtsklick → Öffnen → Öffnen).

Alles Nötige (Segmentierungs-Modell, Schriften, Logo) liegt in `lib/` – es muss nichts
nachgeladen werden.

## iPhone als Kamera

- **Mac:** meist ohne App über „Integration mit Kamera“ (iPhone XR oder neuer, gleiche Apple-ID).
  Sonst App „Camo“ + „Camo Studio“ für Mac.
- **Windows:** App „Camo“ + „Camo Studio“ + „Apple Geräte“ aus dem Microsoft Store, iPhone per Kabel.

Ausführlich inkl. aller Tasten: [ANLEITUNG.txt](ANLEITUNG.txt)

## Wichtigste Tasten

| Taste | |
|---|---|
| H / F | Menü an/aus / Vollbild |
| O | Beamer-Fenster ohne Menü öffnen (Doppelklick = Vollbild) |
| Y X C V J K | ruhige Abend-Looks (Nebel, Flüssig, Rauch …) mit Name/Logo |
| 1–5 · 6–0 | Looks mit Kamera · Club dunkel |
| Q W E R Z U | Looks ohne Kamera |
| Shift+1–0 | Effekte für Name/Logo |
| T | nächste Schrift (für alle Artists) |
